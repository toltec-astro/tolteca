1. One group response, two detuning coordinates

The fitted response maps the jointly recovered resonance frequencies and losses back to every measured probe. For a multiplet, x′ is a component coordinate within that full response; it is not obtained by treating blended I/Q as a single resonator.

xopt,kj = fprobe,k/fres,j − 1,   x′kj = xopt,kj + bj/(rj² + x′kj²),   bj = 2aref,jrref,j³.

The calibrated b is held fixed over this record. This is a local physical assumption, not an independently measured instantaneous nonlinearity. xopt includes intrinsic fluctuations as well as optical response. The first Tune block provides the independent identity-repeatability check; the final block supplies the recorded calibration for this timestream.

δxopt ≈ D δx′ + μ δr,
D = 1 + 2bx′/(r²+x′²)²,   μ = 2br/(r²+x′²)²,
Popt ≈ D²Pprime + μ²Pr + 2Dμ Re Cprime,r.

D and μ come from the same group model at the median recovered frequency/loss state. Their actual ranges over the record remain in the component ledger. The signed cross term is essential. Its sign determines whether the loss coupling reinforces or cancels the other noise terms. The local linear prediction is compared with the measured nonlinear result; exact spectral closure with c = x′ − xopt is an algebraic check, not validation of the physical model.

3. Inspect any fitted component

Choose a component even when it has no complete estimate. Each displayed trajectory uses its declared acquired probe; the reference probe is selected by frequency proximity, not by measured noise. Fits, routing, failures and evidence gaps are retained without a new selection cut.

Displayed time series use every 16th sample; trajectories use complete 1-s means. All 7,802 samples contribute to each Welch estimate: 1,024-sample Hann windows, 50% overlap, constant detrending, one-sided density. Cross-spectrum convention is conj(FFT(first)) × FFT(second). Numerical values use dimensionless detuning/loss and Hz, with no ppm rescaling. Raw samples and complex spectra are retained in each NPZ file.
