1. Correspondence across complete groups

The existing full tone-matcher relation supplies candidates between each Tune block and seven Skydip acquisitions (142440 scans 2–8). The 200 kHz registration window and five-acquisition support requirement are unchanged. Entire target fitting groups and source Skydip groups participate, including findings with no accepted APT receipt.

Within each connected group, retain every order-preserving assignment that covers the smaller feature list. The larger list may have omissions. A pair is supported only if every complete assignment contains it. Failed coverage retains all candidates as unresolved; unknown identities also veto an assignment. No nearest-distance tie-break, majority vote or measured noise is used. This inherits the tone matcher's no-crossing assumption: these are reviewable observation correspondences, not new accepted roster records.

Repeatable forced support must identify the same roster UID without competing or unknown candidates in at least five independent acquisitions, then pass the unique-target and both-Tune-block checks. A matched source finding is resolved through its exact product, interface, acquired block and original row receipt. Equal local component integers do not establish identity.

1.1 Independent response measurements

The former source study excluded all connected groups before testing response. The new extraction tests each constituent with the same seven declared acquisitions. It requires an exact accepted source finding receipt, measured dual S21/D21 feature support, usable native fitting, no fit/bound/edge/channel warnings and a positive local covariance. Multiplicity and nonlinearity are not exclusion flags. {{LAWCOUNT}} source components provide loss/detuning regressions.

For each component, fit loaded loss r against x_opt = f_ref/f_res − 1 using its labelled marginal from the full fitted covariance, including the frequency/loss cross term. The slope is Rᵣ/Rₓ; β = Rₓ/Rᵣ is its reciprocal. Fit uncertainty is conditional on the sweep model. Leave-one-acquisition fits and reduced χ² remain visible; a fitted line is not proof of an optical-only response or of the same responsivity at a different loading.
